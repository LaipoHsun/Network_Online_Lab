# 第 4 章　Dcard 午夜抽卡：為什麼世界這麼小？

**概念**：路徑與距離、平均距離、小世界（small world）、Watts–Strogatz 模型。**前置**：度、聚集係數。**帶走的一句話**：只要極少數「跨圈」的連結，距離就會從和 N 成正比變成和 ln N 成正比，而朋友圈的三角形幾乎不受影響。

**① 場景**：2011 年，兩位台大資管系學生做了 Dcard：[每天午夜 12 點，系統把你隨機配對到別校、別系的一位學生](https://www.bnext.com.tw/article/44423/how-social-media-dcard-reaches-millions-users)。資工系大三的宜蓁抽到一位高雄的醫學系學生，聊天時發現對方的室友是自己國中同學。問題：台灣任意兩個人之間，平均隔幾個人？

**② 預測**：滑桿猜「Facebook 上任兩人的平均距離」（1–10 步），再猜「台灣任兩人」。

**③ 動手玩**

- **場景 A：只認識同系的人**。60 位小人按系所圍成一圈，每人只認識鄰近的 K 位。讀者點任意兩人，看一封「信」沿最短路徑飛過去。
- **場景 B：開啟抽卡**。主要變數是「抽卡成功率」，對應 Watts–Strogatz 的重連機率 p。拉高時，午夜會有幾對小人跨過圓圈連上線，信的路徑立刻變短。下方是「⟨d⟩(p)/⟨d⟩(0) 與 C(p)/C(0)」對數軸曲線圖，標出目前的 p。
- 這章的原型已經做過一版：模型邏輯可以沿用，但要改成小人和信的動畫。

**④ 定義與結構**

```latex
\langle d \rangle = \frac{1}{N(N-1)}\sum_{i \ne j} d_{ij}, \qquad \langle d \rangle_{\text{lattice}} \approx \frac{N}{2K}, \qquad \langle d \rangle_{\text{random}} \approx \frac{\ln N}{\ln \langle k \rangle}
```

- d\_ij 是最短路徑的長度，用 BFS 計算；視覺上用「一層層擴散的漣漪」展示 BFS。
- 規則格子的距離和 N 成正比。隨機網路的推導：從一個人出發，d 步後大約碰到 ⟨k⟩^d 人，令它等於 N 就得到 ln N / ln ⟨k⟩。
- 台灣估算：N ≈ 2,300 萬，假設每人認識約 1,000 人，得到 ⟨d⟩ ≈ 17.0 / 6.9 ≈ 2.5。重點是人口加大十倍，距離只多約 0.33 步。
- Watts–Strogatz：一條捷徑能縮短大量配對的距離，但只拆掉一兩個三角形。所以在一個很寬的 p 區間裡，距離已經接近隨機網路，聚集係數却還接近格子。

**⑤ 邏輯鏈**

1. 假設：多數關係是局部的（同系、同宿舍），少數是隨機的遠距關係（抽卡、交換、搬家）。
2. 推導：遠距關係讓「一步可以到達的人數」從線性增長變成指數增長。
3. 結果：⟨d⟩ 正比於 ln N，同時 C 還很高。
4. 預測：大型社會網路的平均距離很小，而且隨網路變大只緩慢增加。

**⑥ 真實資料**：三個數字排成一條時間線。

- [Travers 和 Milgram 1969](https://www.cse.cuhk.edu.hk/~cslui/CMSC5734/travers69smallworld.pdf)：296 位起點者試圖把信傳給波士頓的一位股票經紀人，64 條鏈成功到達，平均經過 5.2 位中間人，而且 48% 的鏈在最後都經過同樣三個人。
- [Backstrom 等人 2012](https://arxiv.org/pdf/1111.4570)：Facebook 約 7.21 億用戶、690 億條友誼，平均距離 4.74。
- [Facebook 2016](https://research.fb.com/blog/2016/02/three-and-a-half-degrees-of-separation/)：15.9 億用戶，平均距離 4.57，也就是 3.57 個中間人；美國國內為 3.46。

揭曉時要講清楚「距離」和「分隔度數」差 1，可以用這個小陷阱對照讀者的猜測。也要講 Milgram 大部分的信沒有寄到。

**⑦ 意義**

- **社會學**：「大家都認識」的台灣經驗有結構原因：只要有人跨地區、跨階層生活，社會就是一個小世界。Milgram 的「漏斗」現象（少數人承接大部分的鏈）預告了第 7 章的中心性。
- **經濟學**：距離短代表資訊、謠言、金融衝擊都傳得快。市場整合和系統性風險是同一個性質的兩面。

**⑧ 限制**：短路徑「存在」不等於「找得到」（Kleinberg 2000 的可導航性問題）；隨機網路假設每人朋友數相近。下一個問題：如果朋友數很不平均，會發生什麼怪事？→ 第 5 章。

*待查證：台灣人口的最新數字；Kleinberg 2000 出處。*
