# 校園地圖規格

校園地圖是所有章節共用的「舞台」。它是一張**插畫化、示意性的假想校園**，配置參考台大校總區（[臺大校園地圖](https://map.ntu.edu.tw) 的整體相對位置），讓台大學生一看就有熟悉感；但不是精確地圖，也不描摹、不擷取官方地圖或任何地圖圖資的圖像。地標用泛稱，不使用校徽、校名標誌或官方圖示。

## 為什麼不直接用真實地圖

1. 官方地圖網站標示內容僅供參考，且底圖來自第三方圖資，有授權問題。
2. 真實地圖太密：模擬只需要 10–14 個「地點」，多餘的建築會干擾讀者看小人。
3. 示意圖可以把距離壓縮，讓小人在幾秒內走完一趟。

## 版面

- 畫布座標 1000 × 700（橫向）。手機版改用 700 × 1000 的直向版本，地點座標另存一份。
- 俯視、扁平插畫，建築用簡單的圓角方塊加屋頂色帶，沒有透視。
- 背景是淡綠草地，主要道路淺灰，人行道更淺。
- 椰林大道是全圖唯一的「招牌」元素：一條從西北往東的寬大道，兩側一排簡化的椰子樹剪影。

## 地點清單（相對位置參考校總區）

| id | 名稱（顯示文字） | 位置 | 用途（引擎中的焦點） |
| --- | --- | --- | --- |
| `gate` | 校門口 | 西北角 | 進出校園、迎新集合點 |
| `bell` | 鐘 | 大道西端、校門內側 | 地標，不作焦點 |
| `boulevard` | 椰林大道 | 西北 → 東，橫貫北半部 | 路徑；小人常經過的「相遇帶」 |
| `library` | 總圖 | 大道東端 | 自習、讀書會 |
| `lake` | 湖 | 大道北側 | 散步、約會、第 4 章場景 |
| `sci` | 理學院系館 | 大道北側偏東 | 物理系上課 |
| `socsci` | 社科院 | 東南側 | 經濟、政治、社會系上課 |
| `liberal` | 文學院 | 大道南側、靠近校門 | 文學院上課、通識課 |
| `eng` | 工學院／電資 | 大道北側偏西 | 資工、電機上課 |
| `cafeteria` | 小福（餐廳） | 校園中央 | 午餐、宵夜，最大的相遇點 |
| `clubs` | 社辦（活動中心） | 東側 | 社團 |
| `gym` | 體育館與操場 | 東側偏南 | 球隊、晨跑（第 9 章） |
| `dorm_m` | 男生宿舍區 | 西南角 | 宿舍焦點 |
| `dorm_f` | 女生宿舍區 | 南側中段 | 宿舍焦點 |
| `zhoushan` | 舟山路 | 南側東西向小路 | 路徑 |
| `mrt` | 捷運站 | 西南角外側 | 進出校園 |

所有地點的座標、入口點、可容納人數存在 `src/data/campus.json`；路徑網（小人走的路）是一張小圖，存在同一個檔案，引擎用最短路徑讓小人沿路走。

| 3 宵夜 | 宿舍區、小福 |
| 4 抽卡 | 全圖（各學院系館圍成圈），湖 |
| 5 友誼悖論 | 全圖 |
| 6 實習 | 社科院、社辦、總圖 |
| 7 系學會 | 社科院、社辦、體育館 |

非當章使用的地點降低不透明度到 35%。

## 交付與驗收

- `src/components/engine/CampusMap.svelte` 以 SVG 繪製底圖（建築、道路、樹），PixiJS 圖層在上方畫小人。
- 地圖插畫先出三個方向的草稿給作者選，再定稿。
- 驗收：台大學生看到能說出「這是椰林大道、這是總圖」；手機直向版可讀；深色主題有對應配色。
