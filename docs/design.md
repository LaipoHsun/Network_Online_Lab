# 網路實驗室 設計書

Nov 21, 2026 · @Pirin

## 概要

「網路實驗室」是一個中文互動網站，用台大學生的日常生活、會動的小人模擬和真實研究資料，讓大學生讀懂 social network 的數學結構，並對這個研究領域產生興趣。第一季做 9 章社會網路；第二季是合作網路，第三季是移動網路，最後接到台灣研究者的合作網路資料。

**讀者**：台大物理系、經濟系、社會系的大學生。他們看得懂微積分和基礎機率，但不一定讀過網路科學。物理系的讀者在意推導和 scaling，經濟系在意機制與誘因，社會系在意理論和實證。所以每個概念都要同時把數學講清楚，也把背後的社會、經濟意義講出來。

**這份設計書的用途**：交給 Claude Code 照著實作。前六節是全站共用的規格，第 1–9 章是逐章內容規格，最後兩節是技術架構和施工說明。

**成功標準**

- 讀者讀完一章，能說出這個概念的定義、它在數學上的關鍵性質，以及它解釋了什麼真實現象。
- 每一章至少有一個「預測失準」的時刻：讀者先猜，結果和他想的不同。
- 每個數字、研究結果都附原始文獻，可以追溯。
- 手機和桌機都能流暢操作；動畫在一般筆電上維持 60 fps。
- 作者（網站負責人）可以只靠修改 MDX 文字和 JSON 參數就調整內容，不必改動畫程式。

## 設計原則

六條原則，寫任何一章、做任何一個互動時都要對照。

1. **先猜，再看。** 每章先讓讀者對一個具體問題下注，再讓他操作，最後用真實資料揭曉。「我猜錯了」是產生興趣最快的方法。
2. **互動是活的。** 畫面上是會走動、會相遇、會生病的小人，連結是從他們的行為裡長出來的，不是靜態的節點和線。
3. **每個數學概念講三層：定義、結構、意義。** 定義要說清楚公式裡每一項；結構要講範圍、上下界、和其他量的關係、隨 N 的變化；意義要對應到經濟學或社會學的機制與理論。
4. **強調邏輯鏈。** 每章的核心結果都要拆成「假設 → 推導 → 結果 → 可以檢驗的預測」，讓讀者看到結論是怎麼一步步推出來的，以及哪個假設一旦不成立就會變掉。
5. **用真實資料和已知結果來詮釋。** 每章至少一個經典或近年的實證結果，全部用本站的設計系統重新繪圖，不貼論文原圖。模型和資料不一致的地方要主動講，那通常是最有趣的地方。
6. **情境貼近台大學生。** 場景用迎新、宿舍、社團、選課、實習、期末考這些真實經驗。角色的名字、系所、對話要像真的台大生，不要教科書腔。

**不做的事**：不放測驗題，不放程式碼練習，不寫「對應書章」的標示，不用台大校徽或任何官方標誌。

## 網站結構與導覽

首頁是課程地圖，章節內是捲動式敘事。章節各自獨立，讀者可以從任何一章開始。

**頁面清單**

| 頁面 | 網址 | 內容 |
| --- | --- | --- |
| 首頁（課程地圖） | `/` | 網站一句話介紹、一個小人在校園裡走動並自動長出網路的背景動畫、三季的章節卡片 |
| 季頁 | `/s1/` | 第一季九章的卡片，以及概念之間的關係圖 |
| 章節頁 | `/s1/01-degree/` 等 | 八段式捲動敘事（見下一節） |
| 術語表 | `/glossary/` | 所有術語的中英對照、一句定義、第一次出現的章節 |
| 關於 | `/about/` | 作者、資料來源、引用方式、授權 |

**章節卡片**：章號、章名（場景問句）、概念名（中英）、一張該章的代表圖、前置概念、預估閱讀時間。未完成的章節顯示「製作中」，不可點。

**章節內導覽**

- 頂部：章名和一條進度條，標出八段的位置，可以點擊跳轉。
- 前置概念：章首列出這章用到的其他章概念，每個都有一句話的懸浮說明，不必跳走也能讀下去。
- 章尾：「下一個問題」卡片，用本章模型的限制引出另一章。
- 術語：首次出現時中英並列，例如「聚集係數（clustering coefficient）」，點擊可看術語表的定義。

**本地存檔**：只用 localStorage 記住「讀過哪些章」和讀者在預測元件裡的答案，讀不到時網站一樣可用。不做登入。

## 每章敘事骨架

每章都是同樣的八段，用捲動式敘事呈現：桌機上左欄是文字，右欄是固定的視覺區，文字捲到哪一段，視覺就變到哪個狀態。手機上視覺區固定在上半部，文字在下半部捲動。

| 段 | 名稱 | 讀者做什麼 | 規格 |
| --- | --- | --- | --- |
| 1 | 場景提問 | 讀一個台大生活場景 | 150 字以內。一位有名字、有系所的角色遇到一個問題，結尾是一個問句。視覺區是校園視圖，小人在走動 |
| 2 | 你的預測 | 拖滑桿或點選來下注 | 問題要有明確的數字答案。答案存起來，第 6 段拿出來對照 |
| 3 | 動手玩 | 操作模擬 | 一到兩個場景。每個場景只有一個主要變數，另配「現在發生了什麼？」即時說明和三個預設情境按鈕 |
| 4 | 定義與結構 | 讀公式卡 | 每個公式卡包含：公式、每一項的意思、範圍與極端情況、和其他量的關係。公式裡的數字和視覺區的對應元素互相高亮 |
| 5 | 邏輯鏈 | 逐步展開推導 | 「假設 → 推導 → 結果 → 預測」四格，每格可展開看完整推導。標出哪個假設是關鍵的 |
| 6 | 真實資料揭曉 | 看真實研究的結果和自己的猜測對照 | 重繪的研究圖表。標明資料來源、樣本大小、年份。至少一個結果要和第 2 段的預測對照 |
| 7 | 意義 | 讀經濟學、社會學的詮釋 | 2–3 個短段。每段由一個數學性質出發，接到一個具體理論或政策意涵，帶文獻 |
| 8 | 模型的限制 | 看哪裡還沒有答案 | 2–3 項。接到「下一個問題」卡片 |

**篇幅**：一章文字約 2,500–3,500 字，閱讀加操作約 20–30 分鐘。

**公式深度**：主文放定義和結果，配一句直覺；完整推導放在邏輯鏈可展開的區塊裡。推導以「大學二年級理工學生看得懂」為準。

## 視覺語言與設計系統

整體風格是「乾淨的理工講義，加上有生命力的插畫」：排版和圖表要嚴謹、資訊密度高；小人和校園要溫暖、有趣。兩者用同一組色彩綁在一起。

### 色彩 tokens

| Token | 用途 | 淺色主題（初稿） |
| --- | --- | --- |
| `--bg` | 頁面背景 | 帶一點綠的灰白 #F2F3EF |
| `--panel` | 卡片、視覺區背景 | #FBFBF8 |
| `--ink` | 主文字 | #1D2729 |
| `--muted` | 次要文字、弱連結 | #5F6B6C |
| `--accent` | 網路、強連結、重點 | 墨綠 #1D6F66 |
| `--signal` | 捷徑、橋、路徑、讀者的預測 | 磚橘 #C8553D |
| `--ill` | 第 9 章的「生病」狀態 | 待定，需和 `--signal` 區分 |

系所色盤：6 種低彩度顏色，用在小人的衣服上，代表系所或社團。必須通過色盲模擬檢查（紅綠色盲下仍可區分），且不只靠顏色傳達資訊，配件或形狀也要不同。深色主題要另外設計一套，不是簡單反轉。

### 字體

- 標題：Noto Serif TC 600/700，只用在章名和段標。
- 內文：Noto Sans TC 400/500，17px，行高 1.8，每行約 32–36 個中文字。
- 數字與程式：JetBrains Mono，數值用 tabular-nums。
- 公式：KaTeX。

### 小人角色規格

- **造型**：幾何化的扁平小人，圓頭加圓角梯形身體，約 24×36 px（桌機）。不畫五官細節，只用兩個點和一條線表示表情。
- **變化**：髮型 4 種、膚色 4 種、衣服顏色代表系所、配件代表年級或身份（例如背包、耳機、理系的計算機）。
- **狀態**：待機（輕微上下浮動）、走路（兩幀循環）、對話（頭上出現對話框）、開心、生病（顏色變淡、頭上有溫度計）、被選中（外圈發光）。
- **網路視圖下**：小人縮成圓形頭像節點，保留髮型和衣服顏色，讓讀者認得出「這是剛剛那個人」。
- **交付格式**：SVG 拆件（頭、身體、髮型、配件），在執行時組合並烘成 PixiJS 的 texture。設計稿先在 Design 畢布上畫出 12 個代表角色。

### 校園地圖

插畫化的假想校園，有台大的氣味但不是精確地圖：一條椰林大道、一座鐘、總圖、系館區、宿舍區、社辦、操場、餐廳、公館捷運站。地圖是會被重複使用的「舞台」，每章只点亮用得到的區域。地標用泛稱（「總圖」「大道」），不使用校徽或官方圖標。

### 圖表

- 所有真實資料圖都重繪，用同一套軸線、格線、標籤規則。
- 對數軸要明確標示「對數尺度」。
- 每張圖的標題是一句結論（例如「共同朋友越多，越容易變成朋友」），不是變數名。
- 圖下方一行小字標來源：作者、年份、期刊、樣本。
- 讀者的預測用 `--signal` 色的虛線標在圖上。

### 動畫原則

- 動畫只用來表達「改變」和「因果」：連結長出來、訊息傳過去、網路斷裂。不加裝飾性動畫。
- 視圖切換的變形動畫 600–900ms，ease-in-out。
- 開啟 prefers-reduced-motion 時：小人不走動，狀態變化直接跳到結果，但保留顏色變化。

## 共用互動元件

六個元件先做好，九章都用它們組合。章節只提供「劇本」（角色、規則、參數），不重寫引擎。

### 1. 小人引擎（Campus Engine）

- 輸入：角色清單（id、名字、系所、年級、宿舍、社團、外觀），以及一份「日程規則」：每個人在一週內各時段會去哪個地點。
- 模擬：小人依日程在地點之間移動。兩人在同一地點停留時，依章節規則以某個機率「相認識」，形成或加強連結（連結權重 = 累積相處時間）。
- 時間：可以暫停、快轉（1×、4×、16×），有一條「學期週數」時間軸可以拖曳。
- 可重現：所有隨機數用可指定種子的產生器，同一個種子每次結果一樣。
- 效能：模擬邏輯和繪圖分開。節點數 ≤ 200 時在主執行緒跑；超過時移到 Web Worker。

### 2. 雙視圖（Campus ⇄ Network）

- 校園視圖：小人在校園地圖上。連結可以選擇顯示或隱藏。
- 網路視圖：同一群人用 d3-force 排版成網路圖，連結粗細對應權重。
- 切換按鈕在視覺區右上角，切換時每個人從地圖位置平滑移到網路位置。捲動敘事也可以在某一段自動切換。
- 兩個視圖都支援：點選一個人看他的資料卡（名字、系所、朋友數、本章相關指標）、拖曳、縮放。

### 3. 預測元件（Predict）

- 三種形式：數字滑桿、在圖上畫一條曲線、在網路上點選一個人。
- 送出後鎖定，答案存入 localStorage，在第 6 段的揭曉圖上用 `--signal` 虛線標出。
- 允許跳過，但預設鼓勵先猜。

### 4. 邏輯鏈（Logic Chain）

- 橫向四格：假設 → 推導 → 結果 → 預測。手機上變成直向。
- 每格收合時只有一句話；展開後顯示完整推導（KaTeX）。
- 「拿掉這個假設」模式：點一個假設，後面依賴它的格子變灰，並顯示「那會得到什麼」的說明。這是讓讀者理解邏輯依賴的關鍵互動。

### 5. 公式卡（Formula Card）

- 內容：公式；每個符號一行說明；「範圍與極端」；「和誰有關」。
- 連動：滑過公式裡的一個符號，視覺區中對應的元素高亮；公式裡的數字是當下模擬的即時值。

### 6. 資料揭曉圖（Reveal Chart）

- 讀取 `/data/<章>/` 下的 JSON，畫成本站樣式的折線、長條、散佈或分布圖。
- 一開始只顯示讀者的預測，捲動到位後真實資料「畫」出來。
- 來源列在圖下，可點擊。

## 第 1 章　迎新週：你加了多少 LINE 好友？

**概念**：度（degree）、平均度、度分布、稀疏性。**前置**：無。**章末要讓讀者帶走的一句話**：朋友數的分布極不平均，所以「平均一個人有多少朋友」這個數字會誤導你。

**① 場景**：經濟系大一的品妤參加完三天的迎新宿營，LINE 多了 40 位好友。同寝室的室友多了 200 位。品妤開始懷疑自己是不是太安靜。問題：她到底「正不正常」？

**② 預測**：「2011 年的 Facebook 上，一位典型用戶（中位數）有多少朋友？平均數又是多少？」兩個滑桿分別下注。重點在於讀者通常會把兩者猜得很接近。

**③ 動手玩**

- **場景 A：迎新宿營**。80 位新生在三天內參加小隊活動、晚會、夜遊，每次同場就有機率加好友。右側即時畫出度分布直方圖，標出平均數和中位數。主要變數：「社交性差異」。設為 0 時每個人一樣愛交朋友，分布窄而對稱；調高時，少數「交際花」形成長尾，平均數和中位數拉開。
- **場景 B：點你自己**。讀者選一位小人當作自己，看他在分布中的百分位。視圖切到網路圖，節點大小對應度。

**④ 定義與結構**

```latex
k_i = \sum_j A_{ij}, \qquad \langle k \rangle = \frac{1}{N}\sum_i k_i = \frac{2L}{N}, \qquad \rho = \frac{L}{\binom{N}{2}} = \frac{\langle k \rangle}{N-1}
```

- 鄰接矩陣 A 是整章的起點：A\_ij = 1 代表 i 和 j 是朋友。度就是一列的總和。
- 握手定理：每條連結被兩端各算一次，所以所有度的總和是 2L。這是讀者第一個「從定義導出的結構」。
- 稀疏性：真實網路的 ⟨k⟩ 遠小於 N，所以密度 ρ 越大的網路越接近 0。你只認識全體學生中極少的一部分。
- 度分布 p\_k = 度為 k 的人所佔比例。平均數和中位數只有在分布對稱時相等；右偏時平均數大於中位數。變異數 ⟨k²⟩ − ⟨k⟩² 在第 5 章會再出現。

**⑤ 邏輯鏈**

1. 假設：每次相遇以機率 p 成為朋友，而每個人的相遇次數和 p 都一樣。
2. 推導：度是許多獨立小機率事件的總和，近似 Poisson 分布，標準差約為 √⟨k⟩。
3. 結果：幾乎沒有人的朋友數是平均的十倍。
4. 可檢驗的預測：平均數 ≈ 中位數。拿掉「大家一樣愛交朋友」的假設後，預測就會失效。這正是第 ⑥ 段要揭曉的。

**⑥ 真實資料**：[Ugander 等人 2011](https://arxiv.org/abs/1111.4503) 分析了 2011 年 5 月 Facebook 全部 7.21 億活躍用戶，99.91% 的人在同一個連通群裡。[結果顯示](https://dgarcia-eu.github.io/FoundationsOfCSS-TUGraz/07_SNA/073_FriendshipParadox/facebook-analysis.pdf) 10% 的人朋友少於 10 位、20% 少於 25 位，中位數超過 100 位，但平均數是 190 位。重繪成累積分布圖，把讀者的兩個預測用虛線標在上面。

**⑦ 意義**

- **經濟學**：朋友數是一種稀缺資源（時間和注意力）分配的結果，而它的分配和所得一樣右偏。用平均數設計的政策（例如「平均每個學生有 N 個可以求助的人」）會高估大多數人的處境。
- **社會學**：度是最簡單的社會資本指標。它的不平等讓「人脈」本身成為階層化的來源。稀疏性也說明每個人只看得到社會的一小塊，這是後面友誼悖論和比較心理的基礎。

**⑧ 限制**：線上好友不等於真實朋友；Facebook 有 5,000 人的好友上限；度忽略了關係強弱（第 6 章）。下一個問題：這些朋友是從哪裡來的？→ 第 2 章。

## 第 2 章　宿舍、系所還是年級：你的朋友從哪裡來？

**概念**：二分網路（bipartite network）、投影（projection）、焦點理論（focus theory）。**前置**：度。**帶走的一句話**：朋友關係大多是「一起參與某件事」的副產品，所以制度設計（住哪、修什麼課）會塑造社會網路。

**① 場景**：社會系大二的語涵翻了自己的好友清單，發現大一住宿舍認識的人比同系的還多。問題：對大學生來說，決定朋友圈的是宿舍、系所、年級還是高中？

**② 預測**：把「宿舍、主修、年級、高中」拖曳排序，猜哪個最能解釋大學生的社群結構。

**③ 動手玩**

- **場景 A：一學期的校園日程**。70 位學生，每人屬於一個宿舍、一個系、一兩個社團、幾門通識課。校園視圖裡，小人每天在這些地點之間移動。主要變數：四個「焦點權重」滑桿，例如把宿舍調成「一年一換」或「四年同一棟」。
- **場景 B：兩種畫法**。左邊是二分圖：一側是人，另一側是地點或組織。點「投影」後，地點節點消失，只留下人與人的連結。讀者會看到一個 30 人的通識課瞬間變成一個 30 人的全連通團塊。

**④ 定義與結構**

```latex
B \in \{0,1\}^{N \times M}, \qquad P = B B^{\top}, \qquad P_{ij} = \sum_{m} B_{im} B_{jm}
```

- B 是關聯矩陣：B\_im = 1 代表學生 i 屬於焦點 m。P\_ij 是兩人共同的焦點數。
- 一個有 s 個成員的焦點，投影後會產生 s(s−1)/2 條連結。大焦點的投影會產生大量「假的」連結，這是投影最常見的陷阱。
- 投影本身就會製造三角形：同一焦點的成員兩兩相連。所以投影網路的聚集係數偏高，這個觀察接到第 3 章。

**⑤ 邏輯鏈**

1. 假設（Feld 的焦點理論）：人們在共同的活動中心相遇，而且焦點越小、互動越密集，越容易產生朋友。
2. 推導：誰和誰是朋友，大部分可以用「兩人共同焦點的數量與性質」來預測。
3. 結果：哪個焦點主導社群結構，取決於制度（例如宿舍是否多年固定）。
4. 預測：住宿制度不同的學校，社群會被不同的屬性主導。

**⑥ 真實資料**：[Traud、Mucha、Porter 2012](https://www.math.ucla.edu/~mason/papers/datadump.pdf) 分析了 Facebook100 資料集：2005 年 9 月，Facebook 還只開放 .edu 信箱時，最早加入的 100 所美國大學的完整好友網路，每校 762 到約 5 萬人。[結果](https://news.ncsu.edu/2012/04/wms-traud-facebook/)：多數社群由同年級的人組成，部分學校則由宿舍主導；主修和高中幾乎不影響。由宿舍主導的學校，往往宿舍較小或學生會連住好幾年。揭曉圖：用讀者的排序對照論文的排序。「主修幾乎沒影響」通常會讓台大讀者很意外，這裡要提問：台大的系所制度比美國強，結果會一樣嗎？

**⑦ 意義**

- **社會學**：Feld 的焦點理論把「為什麼會認識」從個人偏好移到結構機會。同質性（homophily）有很大一部分可能不是「喜歡和自己像的人」，而是「只遇得到和自己像的人」。
- **經濟學**：宿舍分配是研究同儕效應（peer effects）最好的自然實驗。Sacerdote（2001）用 Dartmouth 的隨機室友分配估計室友對成績的影響。對學校來說，住宿政策就是在設計社會網路。

**⑧ 限制**：投影會丟失資訊（不知道兩人是在哪個焦點認識的）；焦點本身是內生的（你可能是因為朋友才加入社團）。下一個問題：朋友的朋友會不會變成你的朋友？→ 第 3 章。

*待查證：Feld 1981 焦點理論、Sacerdote 2001 的出處細節。*

## 第 3 章　室友的朋友：為什麼朋友圈會「收合」？

**概念**：三元閉合（triadic closure）、聚集係數（clustering coefficient）、遷移性（transitivity）。**前置**：度、投影。**帶走的一句話**：社會網路的三角形比隨機網路多上好幾個數量級，而且這是一個「會自我強化」的過程。

**① 場景**：物理系大一的承恩和室友一起去吃宵夜，室友帶了自己的高中同學。一個學期後，他和那位同學已經會自己約打球。問題：兩個有共同朋友的陌生人，變成朋友的機率有多高？和共同朋友的數量有什麼關係？

**② 預測**：在一張空白圖上畫一條曲線：橫軸是共同朋友數（0–5），縱軸是「之後變成朋友的機率」。

**③ 動手玩**

- **場景 A：一個學期的宵夜**。60 位學生，每晚有人拉朋友一起去吃宵夜。新形成的三角形會閃一下。主要變數：「帶朋友去吃宵夜的機率」，也就是三元閉合的強度。另一個參照組是「隨機在餐廳遇到」。右側即時畫出 C(t) 和同樣連結數的隨機網路的 C。
- **場景 B：放大一個人**。點一位小人，畫面只留下他和他的朋友。朋友之間實際存在的連結亮起，可能存在但還沒存在的連結用虛線標出，直接對應公式的分子和分母。

**④ 定義與結構**

```latex
C_i = \frac{2L_i}{k_i(k_i-1)}, \qquad C_{\triangle} = \frac{3 \times \text{三角形數}}{\text{連通的三元組數}}, \qquad C_{\text{random}} \approx \frac{\langle k \rangle}{N}
```

- C\_i 的分母是 i 的朋友之間「最多可能」有幾條連結，分子 L\_i 是實際有幾條。範圍是 0 到 1。
- 平均局部聚集係數和全域遷移性是兩個不同的量，度很不均的網路裡可能差很多。這是讀論文時常見的陷阱，要講。
- 隨機網路的 C ≈ ⟨k⟩/N，會隨 N 變大而趨近 0。社會網路的 C 則大致不隨 N 變化。「C 不趨近 0」本身就是社會網路不是隨機的證據。
- 許多真實網路裡 C(k) 隨 k 下降：朋友很多的人，朋友之間比較不認識。

**⑤ 邏輯鏈**

1. 假設：有共同朋友的兩人，相遇機會更多（機會），也更信任彼此（信任），而且拒絕交流會讓共同朋友尷尬（平衡）。
2. 推導：共同朋友每多一位，相遇和成為朋友的機率就增加。
3. 結果：新連結偏好封閉三角形，三角形越多又讓下一次閉合更容易，C 維持在高水準。
4. 預測：「變成朋友的機率」隨共同朋友數上升。

**⑥ 真實資料**：[Kossinets 和 Watts 2006](https://cse.iitk.ac.in/users/cs888/files/good.pdf)（*Science*）分析了美國一所大型大學 43,553 位師生職員在一學年內[約 1,458 萬封 email](https://www.sciencenews.org/article/college-friendships-and-social-networks)，配對了每個人的身分、修課等屬性。[結果](https://research.google/pubs/origins-of-homophily-in-an-evolving-social-network/)顯示新連結的形成強烈偏向三元閉合和焦點閉合（同修一門課）：共同朋友和共同課程越多，形成新連結的機率越高。揭曉圖：重繪論文「新連結機率 × 共同朋友數 × 共同課程數」的圖，疊上讀者畫的曲線。另外可加一個小數字：[Pew 2012](https://www.pewresearch.org/internet/2012/02/03/part-3-the-structure-of-friendship) 樣本中，Facebook 用戶好友圈的平均密度是 0.12。

**⑦ 意義**

- **社會學**：Coleman 的「封閉性」論點。三角形多的群體容易建立規範和信任，因為你對一個人的行為，共同朋友都看得到。代價是資訊重複、觀點同質化，這正好是第 6 章弱連結的伏筆。
- **經濟學**：在合約無法執行的場合（借錢、互助、共同計畫），共同朋友就是執行機制：你違約，失去的不只一個關係。Jackson、Rodriguez-Barraquer 和 Tan（2012）把這個概念稱為「被支持的關係」。

**⑧ 限制**：email 不等於友誼；三元閉合和同質性、共同焦點很難分開。下一個問題：如果大家都只在自己的小圈圈裡，為什麼世界還是很小？→ 第 4 章。

*待查證：Jackson, Rodriguez-Barraquer & Tan 2012 (AER) 的出處細節。*

## 第 4 章　Dcard 午夜抽卡：為什麼世界這麼小？

**概念**：路徑與距離、平均距離、小世界（small world）、Watts–Strogatz 模型。**前置**：度、聚集係數。**帶走的一句話**：只要極少數「跨圈」的連結，距離就會從和 N 成正比變成和 ln N 成正比，而朋友圈的三角形幾乎不受影響。

**① 場景**：2011 年，兩位台大資管系學生做了 Dcard：[每天午夜 12 點，系統把你隨機配對到別校、別系的一位學生](https://www.bnext.com.tw/article/44423/how-social-media-dcard-reaches-millions-users)。資工系大三的宜蓁抽到一位高雄的醫學系學生，聊天時發現對方的室友是自己國中同學。問題：台灣任意兩個人之間，平均隔幾個人？

**② 預測**：滑桿猜「Facebook 上任兩人的平均距離」（1–10 步），再猜「台灣任兩人」。

**③ 動手玩**

- **場景 A：只認識同系的人**。60 位小人按系所圍成一圈，每人只認識鄰近的 K 位。讀者點任意兩人，看一封「信」沿最短路徑飛過去。
- **場景 B：開啟抽卡**。主要變數是「抽卡成功率」，對應 Watts–Strogatz 的重連機率 p。拉高時，午夜會有幾對小人跨過圓圈連上線，信的路徑立刻變短。下方是「⟨d⟩(p)/⟨d⟩(0) 與 C(p)/C(0)」對數軸曲線圖，標出目前的 p。
- 這章的原型已經做過一版：模型邏輯可以沿用，但要改成小人和信的動畫。

**④ 定義與結構**

```latex
\langle d \rangle = \frac{1}{N(N-1)}\sum_{i \ne j} d_{ij}, \qquad \langle d \rangle_{\text{lattice}} \approx \frac{N}{2K}, \qquad \langle d \rangle_{\text{random}} \approx \frac{\ln N}{\ln \langle k \rangle}
```

- d\_ij 是最短路徑的長度，用 BFS 計算；視覺上用「一層層擴散的漣漪」展示 BFS。
- 規則格子的距離和 N 成正比。隨機網路的推導：從一個人出發，d 步後大約碰到 ⟨k⟩^d 人，令它等於 N 就得到 ln N / ln ⟨k⟩。
- 台灣估算：N ≈ 2,300 萬，假設每人認識約 1,000 人，得到 ⟨d⟩ ≈ 17.0 / 6.9 ≈ 2.5。重點是人口加大十倍，距離只多約 0.33 步。
- Watts–Strogatz：一條捷徑能縮短大量配對的距離，但只拆掉一兩個三角形。所以在一個很寬的 p 區間裡，距離已經接近隨機網路，聚集係數却還接近格子。

**⑤ 邏輯鏈**

1. 假設：多數關係是局部的（同系、同宿舍），少數是隨機的遠距關係（抽卡、交換、搬家）。
2. 推導：遠距關係讓「一步可以到達的人數」從線性增長變成指數增長。
3. 結果：⟨d⟩ 正比於 ln N，同時 C 還很高。
4. 預測：大型社會網路的平均距離很小，而且隨網路變大只緩慢增加。

**⑥ 真實資料**：三個數字排成一條時間線。

- [Travers 和 Milgram 1969](https://www.cse.cuhk.edu.hk/~cslui/CMSC5734/travers69smallworld.pdf)：296 位起點者試圖把信傳給波士頓的一位股票經紀人，64 條鏈成功到達，平均經過 5.2 位中間人，而且 48% 的鏈在最後都經過同樣三個人。
- [Backstrom 等人 2012](https://arxiv.org/pdf/1111.4570)：Facebook 約 7.21 億用戶、690 億條友誼，平均距離 4.74。
- [Facebook 2016](https://research.fb.com/blog/2016/02/three-and-a-half-degrees-of-separation/)：15.9 億用戶，平均距離 4.57，也就是 3.57 個中間人；美國國內為 3.46。

揭曉時要講清楚「距離」和「分隔度數」差 1，可以用這個小陷阱對照讀者的猜測。也要講 Milgram 大部分的信沒有寄到。

**⑦ 意義**

- **社會學**：「大家都認識」的台灣經驗有結構原因：只要有人跨地區、跨階層生活，社會就是一個小世界。Milgram 的「漏斗」現象（少數人承接大部分的鏈）預告了第 7 章的中心性。
- **經濟學**：距離短代表資訊、謠言、金融衝擊都傳得快。市場整合和系統性風險是同一個性質的兩面。

**⑧ 限制**：短路徑「存在」不等於「找得到」（Kleinberg 2000 的可導航性問題）；隨機網路假設每人朋友數相近。下一個問題：如果朋友數很不平均，會發生什麼怪事？→ 第 5 章。

*待查證：台灣人口的最新數字；Kleinberg 2000 出處。*

## 第 5 章　為什麼你的朋友好像都比你受歡迎？

**概念**：友誼悖論（friendship paradox）、以連結為單位的抽樣。**前置**：度分布。**帶走的一句話**：這不是心理錯覺，而是一個數學定理；而且它可以拿來使用。

**① 場景**：期中考周，社工系大一的家瑄滑 IG，覺得每個朋友都在聚餐、出遊、參加活動，只有自己在圖書館。問題：她的朋友真的平均比她受歡迎嗎？這對多少人來說成立？

**② 預測**：「在一個 Facebook 樣本中，有多少比例的人，朋友數少於自己朋友的平均朋友數？」滑桿 0–100%。

**③ 動手玩**

- **場景 A：每個人頭上的兩個數字**。網路視圖裡，每個小人頭上顯示「我的朋友數 / 我朋友的平均朋友數」。前者較小的人變成藍色。主要變數是「社交性差異」：差異為 0 時（每人朋友數一樣），悖論消失；差異越大，藍色的人越多。
- **場景 B：兩種抽樣**。「隨機點一個人」和「隨機點一條連結，取它的一端」各抽 200 次，兩個直方圖並排。讀者會看到第二種抽法系統性地抽到交際花。
- **場景 C：期末流感哨兵**。從場景 B 抽出兩組人（隨機組 vs. 朋友組），放一場流感，看哪一組先發病。這是第 9 章傳染的預告。

**④ 定義與結構**

```latex
\mathbb{E}[\,k \text{ of a random friend}\,] = \frac{\sum_k k \cdot k\,p_k}{\sum_k k\,p_k} = \frac{\langle k^2 \rangle}{\langle k \rangle} = \langle k \rangle + \frac{\sigma_k^2}{\langle k \rangle} \;\ge\; \langle k \rangle
```

- 關鍵一步：「隨機選一個朋友」等於「隨機選一條連結的一端」。度為 k 的人有 k 條連結，所以被抽到的機率和 k 成正比。這叫做大小偏差抽樣（size-biased sampling）。
- 等號成立若且唯若變異數為 0，也就是每個人朋友數完全一樣。度分布越不平均，悖論越嚴重。這把第 1 章的「長尾」和這章連在一起。
- 上式是「全體平均」的版本。「個人的朋友平均比她多」是另一個、較弱的命題，需要額外假設（例如度相關性）。主文要區分這兩者，推導放在可展開區塊。

**⑤ 邏輯鏈**

1. 假設：朋友數有差異（σ² > 0）。這是唯一的假設。
2. 推導：朋友是按連結數加權抽出來的，所以平均度比全體平均多出 σ²/⟨k⟩。
3. 結果：大多數人的朋友都比自己受歡迎。不是你太孤僻，是抽樣方式。
4. 預測：「朋友的朋友」比隨機的人更中心，所以在傳染病中會較早被感染。

**⑥ 真實資料**

- [Pew 2012](https://www.pewresearch.org/internet/2012/02/03/part-3-the-structure-of-friendship)：樣本中 Facebook 用戶平均有 245 位朋友，但他們的朋友平均有 359 位；84% 的用戶朋友數少於自己朋友的平均。只有朋友數前 10%（超過 780 位）的人才比自己的朋友多。這是第 ② 段預測的答案。
- [Christakis 和 Fowler 2010](https://pmc.ncbi.nlm.nih.gov/articles/PMC2939797)：2009 年哈佛流感期間，[隨機選出 319 位大學生，請他們提名 425 位朋友](https://www.cidrap.umn.edu/influenza-general/study-friend-sentinels-provide-early-flu-warning)，共追蹤 744 人。[朋友組的疫情進展比隨機組早了 13.9 天](https://escholarship.org/uc/item/1h640762)（95% 信賴區間 9.9–16.6 天）。揭曉圖：兩條累積感染曲線，和場景 C 的模擬結果對照。

**⑦ 意義**

- **社會學**：社群媒體上「大家都過得比我好」的感受有一部分是結構性的。同樣的抽樣偏差也適用於「你的朋友比你更活躍」「你修的課比平均擁擠」。
- **經濟學與政策**：只知道局部資訊就能找到中心人物。疫苗不夠時，「請隨機選出的人指定一位朋友打疫苗」比隨機打更有效（Cohen 等人 2003 的「熟人免疫」）。調查設計也要注意：用滾雪球抽樣會系統性地高估社交性。

**⑧ 限制**：個人層級的悖論不必然對每個人成立；線上「看到的」朋友還受推薦演算法影響。下一個問題：哪些朋友對你最有用？→ 第 6 章。

*待查證：Cohen, Havlin & ben-Avraham 2003 出處。*

## 第 6 章　暑期實習，是誰介紹的？

**概念**：連結強度、鄰居重疊度、橋與局部橋、弱連結的力量、滲流。**前置**：聚集係數、小世界。**帶走的一句話**：新資訊只能從橋上進來，而橋幾乎都是弱連結。但「最弱」不是最好。

**① 場景**：大三經濟系的小瑜在找暑期實習。她最好的朋友們和她修一樣的課、投一樣的公司，知道的職缺也都一樣。最後介紹她進公司的，是大一服務學習課上只見過幾次面的學姊。

**② 預測**：「透過人脈找到工作的人中，介紹人是『常常見面』、『偶爾見面』、『很少見面』的各佔多少？」拖一個三段的比例條。

**③ 動手玩**

- **場景 A：職缺怎麼傳到你手上**。校園視圖裡約 70 位學生，分成幾個系和社團的小圈圈。連結粗細是模擬中累積的相遇次數。一個發光的「實習職缺」從某個圈圈出現，沿連結傳出去。讀者可以切換「只透過強連結傳」和「也透過弱連結傳」，看職缺能不能跑出圈子、多久到小瑜手上。
- **場景 B：剪斷實驗**。兩個按鈕：「從最弱的開始剪」和「從最強的開始剪」。小人網路即時斷裂，旁邊同步畫出最大連通群比例 S(f)。剪弱的時網路在某個門檻崩解，剪強的只會慢慢縮小。

**④ 定義與結構**

```latex
O_{ij} = \frac{n_{ij}}{(k_i - 1) + (k_j - 1) - n_{ij}}, \qquad S(f) = \frac{|\text{最大連通群}|}{N}\ \text{（剪掉 } f \text{ 比例的連結後）}
```

- w\_ij 是連結強度（見面頻率、通話時間）。n\_ij 是 i、j 的共同朋友數。O\_ij = 0 代表局部橋，O\_ij = 1 代表兩人朋友圈完全重疊。
- 橋：拿掉後網路分裂的連結。局部橋：兩端沒有共同朋友的連結；它的「跨度」是拿掉後兩端的距離。
- S(f) 在某個 f\_c 突然掉到接近 0，是一個相變。這是物理系讀者會認得的滲流門檻。

**⑤ 邏輯鏈**（「拿掉這個假設」的示範章）

1. 假設：Granovetter 的「禁止三角形」。如果 A–B 和 A–C 都是強連結，B–C 至少有弱連結。
2. 推導：任何局部橋都不可能是強連結。反證：若 A–B 是強連結又是局部橋，而 A 還有其他強連結 C，則 B–C 必存在，A–B 就不是局部橋了。用三個小人的動畫示範。
3. 結果：強連結的朋友知道的事你大多也知道，新資訊從弱連結進來。
4. 預測：(a) 工作資訊多半來自弱連結；(b) 連結越強，O\_ij 越高；(c) 先剪弱連結會讓網路崩解。

讀者點「拿掉禁止三角形」時，第 2–4 格變灰，並顯示：「強連結也可以是橋，弱連結的優勢就不再保證」。

**⑥ 真實資料**

- **Granovetter 1973**：透過人脈找到工作的人中，[16.7% 的介紹人是常見面的，55.6% 是偶爾見面的，27.8% 是很少見面的](https://law-journals-books.vlex.com/vid/labor-market-implications-weak-ties-54952367)。對照第 ② 段的比例條。
- **[Onnela 等人 2007](https://pubmed.ncbi.nlm.nih.gov/17456605/)**（*PNAS*）：數百萬手機用戶的通話網路。連結強度和局部結構耦合；剪強連結網路仍穩健，剪弱連結則在一個相變後崩解。預測 (b)、(c) 成立。場景 B 就是重現這張圖。
- **[Rajkumar 等人 2022](https://pubmed.ncbi.nlm.nih.gov/36107999/)**（*Science*）：LinkedIn [在五年間對超過 2,000 萬人](https://ide.mit.edu/wp-content/uploads/2022/09/abl4476.pdf?x19295)隨機調整「你可能認識的人」推薦，[產生約 20 億條新連結和 60 萬份新工作](https://www.Gwern.net/doc/sociology/technology/2022-rajkumar.pdf)。結果是倒 U 型：用共同朋友數衡量時，「中等弱」的連結最能帶來新工作。這是「真實資料修正理論」的時刻。
- **反例：[邊燕傑 1997](https://acnpsearch.tweb-dev.unibo.it/singlejournalindex/7426245)**（*ASR*）：1988 年天津的調查發現，工作更常透過強連結取得，因為「關係」傳遞的是影響力而非資訊。留一個問題給讀者：台灣比較像哪一邊？

**⑦ 意義**

- **經濟學**：勞動市場有資訊摩擦，網路是搜尋的管道。[Calvó-Armengol 和 Jackson 2004](https://econpapers.repec.org/RePEc:aea:aecrev:v:94:y:2004:i:3:p:426-454)（*AER*）證明：當工作資訊沿網路流動時，就業狀態在朋友之間正相關，一個起點較差的群體會持續落後。內推制度會複製不平等。
- **社會學**：社會資本有兩種來源。Burt 的結構洞強調橋帶來新資訊；Coleman 的封閉性（第 3 章）強調強連結帶來信任。倒 U 型結果說明兩者需要平衡：太弱的連結沒人願意幫你。

**⑧ 限制**：「強度」該用互動頻率還是共同朋友數？兩者在 LinkedIn 研究中結果不同；文化差異。下一個問題：如果橋這麼重要，站在橋上的人是不是很有權力？→ 第 7 章。

**驗收**：剪斷時連結有斷裂動畫，S(f) 曲線同步更新、延遲 < 100ms；重繪倒 U 圖時標出「共同朋友數」是 x 軸定義；手機寬度下兩個場景都可操作。

## 第 7 章　系學會的消息，為什麼都經過他？

**概念**：中心性（centrality）：度、接近、介數、特徵向量。**前置**：路徑與距離、橋。**帶走的一句話**：「誰最重要」沒有唯一答案，每種中心性都對應一種「東西怎麼在網路上流動」的假設。

**① 場景**：政治系大二的子軒發現，系上什麼八卦都是從同一位學長傳出來的。他朋友不算最多，但他同時在系學會、籃球隊和吉他社。問題：朋友最多的人，就是最有影響力的人嗎？

**② 預測**：在一個 40 人的小人網路上點選「你覺得最重要的人」。之後四種中心性會各自指出一個人，看讀者的選擇和哪種一致。

**③ 動手玩**

- **場景 A：四種眼鏡**。同一張網路，切換四個按鈕，小人的大小跟著變。每種中心性配一個「流動」動畫：度 = 誰的對話框最多；接近 = 從他發出的漣漪最快覆蓋全體；介數 = 大量「信」穿過他；特徵向量 = 重複傳播時熱度累積在哪裡。
- **場景 B：拿掉一個人**。點一位小人讓他「休學」，看平均距離和最大連通群怎麼變。拿掉度最高的人和介數最高的人，結果往往不同。

**④ 定義與結構**

```latex
C_B(i) = \sum_{s \ne i \ne t} \frac{\sigma_{st}(i)}{\sigma_{st}}, \qquad C_C(i) = \frac{N-1}{\sum_j d_{ij}}, \qquad A\mathbf{x} = \lambda_1 \mathbf{x}
```

- 介數中心性：σ\_st 是 s 到 t 的最短路徑數，σ\_st(i) 是其中經過 i 的數量。它量的是「多少人之間的消息要靠你傳」。
- 接近中心性：平均距離的倒數。特徵向量中心性：你的重要性來自你朋友的重要性，是一個自我參照的定義，解是鄰接矩陣最大特徵值的特徵向量（Perron–Frobenius 保證它為正）。
- 結構關係：在很多網路裡四種中心性高度相關，但「度不高、介數很高」的人就是橋和經紀人，是最有趣的例外。

**⑤ 邏輯鏈**

1. 假設：資訊（或資源、權力）沿最短路徑流動。
2. 推導：位於很多最短路徑上的人能看到、延遲或改寫流過的東西。
3. 結果：介數中心性是一種「結構性權力」，不必然來自朋友多。
4. 預測：連接兩個不跟彼此往來的群體的人，能獲得不成比例的影響力。

「拿掉假設」：如果資訊是隨機遊走而不是走最短路徑，介數中心性就不是對的量尺，要改用特徵向量或 Katz 中心性。

**⑥ 真實資料**

- [Padgett 和 Ansell 1993](https://dl1.cuni.cz/mod/resource/view.php?id=341254)（*AJS*）：1400–1434 年佛羅倫斯菁英家族的婚姻與商業網路。梅迪奇家族的權力來自菁英網路中的斷裂處，而只有他們跨越了這些斷裂。後續分析發現[梅迪奇在婚姻網路中的度、接近、介數中心性都最高](https://arxiv.org/pdf/1401.0655)。揭曉圖：15 個家族的婚姻網路（公開資料集），節點大小 = 介數；讓讀者先在不知道名字時猜誰是梅迪奇。
- 回到 Milgram：[最後一站是「G 先生」的鏈佔了 64 條中的 16 條](https://www.cis.upenn.edu/~mkearns/teaching/NetworkedLife/navigation18.pdf)。

**⑦ 意義**

- **社會學**：Burt 的結構洞理論：位於兩個群體之間的人可以獲得資訊優勢和控制優勢。梅迪奇的「穩健行動」是歷史上的經典例子。
- **經濟學**：Ballester、Calvó-Armengol 和 Zenou（2006）證明，在有同儕外部性的賽局裡，均衡行為正比於 Katz–Bonacich 中心性；「關鍵人物」就是拿掉後總產出下降最多的人。Banerjee 等人（2013）在印度村莊發現，從中心性高的人開始推廣微型貸款，參與率更高。

**⑧ 限制**：中心性量的是「位置」不是「意願」；史料網路有倖存者偏誤。下一個問題：網路自己分成了哪幾群？→ 第 8 章。

*待查證：Ballester et al. 2006 (Econometrica)、Banerjee et al. 2013 (Science) 出處。*

## 第 8 章　社團吵架分成兩派：演算法猜得到誰站哪邊嗎？

**概念**：社群（community）、模組度（modularity）、社群偵測。**前置**：度、聚集係數、介數中心性。**帶走的一句話**：「群」的定義是「內部連結比隨機預期的多」，而不是「內部連結很多」。

**① 場景**：台大某個武術社，社長和教練為了是否要漲社費吵了一學期。社員們開始選邊站。問題：如果只知道「誰和誰在社辦外也會一起出去」，能預測分裂後每個人站哪一邊嗎？

**② 預測**：讀者在 34 人的網路上自己畫一條線把社團分成兩半（拖曳小人到左右兩邊）。送出後計算他的分法的 Q 值。

**③ 動手玩**

- **場景 A：你來分群**。讀者拖曳小人到不同的顏色區，Q 值即時更新。內部連結變綠、跨群連結變橘。可以按「讓演算法來」看 Louvain 一步一步合併。
- **場景 B：切斷橋樑**。Girvan–Newman 演算法的動畫版：反覆移除介數最高的連結，社團自己裂成兩半。這把第 7 章和本章接起來。
- \*\*場景 C：隨機網路也有「群」嗎？\*\*在一個隨機網路上跑同一個演算法，也會得到正的 Q。用來講「找到群」不等於「群是真的」。

**④ 定義與結構**

```latex
Q = \frac{1}{2m}\sum_{i,j}\left[A_{ij} - \frac{k_i k_j}{2m}\right]\delta(c_i, c_j)
```

- m 是連結數，c\_i 是 i 的群別。k\_i k\_j / 2m 是「保留每個人度數的隨機網路」裡 i、j 之間的預期連結數（configuration model）。
- Q 是「實際的群內連結比例減掉預期比例」。把所有人放在一群時 Q = 0。
- 結構性質：最大化 Q 是 NP-hard，所以都用啟發式演算法；有解析度限制（太小的群會被合併）；物理系讀者可以認出它和 Potts 模型能量函數的對應。

**⑤ 邏輯鏈**

1. 假設：群內的人互動比隨機預期多，群間的互動比預期少。
2. 推導：沒有任何「標籤」，只看連結結構就能找出使 Q 最大的分法。
3. 結果：網路結構裡藏著社會分組。
4. 預測：當群體真的分裂時，分裂線會沿著演算法找出的邊界走。

**⑥ 真實資料**：[Zachary 空手道社](https://en.wikipedia.org/wiki/Zachary%27s_karate_club)。Zachary 在 1970–1972 年觀察了美國一所大學空手道社 34 位在社團外也有互動的成員。期間管理者「John A」和教練「Mr. Hi」產生衝突，社團分裂為二，[Zachary 的方法正確預測了除一人外所有人的去向](https://www.wikipedia.org/wiki/Zachary_Karate_Club)。Girvan 和 Newman 2002 年用它測試社群偵測，[也只分錯一個節點](https://arxiv.org/pdf/0905.4103)。揭曉動畫：先顯示讀者的分法，再顯示演算法的分法，最後顯示真實的分裂，那個被分錯的人要特別標出來討論。可加入 Facebook100 的「年級主導社群」作為大尺度的例子（第 2 章）。

**⑦ 意義**

- **社會學**：派系、階級、極化都可以是「網路裡的群」。群之間連結稀少，代表對立的兩邊很少有直接對話的管道。
- **經濟學**：社群結構會將資訊困在群內，形成「資訊孤島」；Onnela 2007 的模擬也顯示資訊會被困在社群裡（第 6 章）。群內的高信任也支撑非正式保險和合作。

**⑧ 限制**：模組度有解析度限制；真實的人可能同時屬於多個群（重疊社群）；34 人的例子很經典但很小。下一個問題：這些群和橋，影響東西怎麼傳開嗎？→ 第 9 章。

*待查證：分裂的原因（文獻記載為課費爭議）、「台大武術社」為虛構場景，頁面要註明。*

## 第 9 章　期末流感和晨跑習慣：為什麼病毒和行為傳得不一樣？

**概念**：簡單傳染（SI/SIR）、複雜傳染（門檻模型）、傳播門檻。**前置**：小世界、友誼悖論、聚集係數。**帶走的一句話**：讓病毒傳得快的結構（捷徑），恰好讓行為傳得慢；第 4 章的結論在這裡被推翻了一半。

**① 場景**：期末考前兩週，男生宿舍有人開始咳嗽。同一週，女生宿舍有人發起「七點晨跑」，希望大家一起跑。問題：哪一個會傳得比較快、比較遠？你想讓晨跑的人變多，該怎麼安排誰跟誰住一起？

**② 預測**：「在一個三角形很多的網路和一個隨機網路上，哪個會讓『加入健康論壇』這個行為傳得更快？」二選一，再對病毒問同一個問題。

**③ 動手玩**

- **場景 A：流感（簡單傳染）**。一位小人生病，每次和朋友碰面以機率 β 傳染，以機率 μ 康復。讀者可以切換「只有同寝室」和「加入社團捷徑」。右側畫感染曲線。
- **場景 B：晨跑（複雜傳染）**。一個小人要看到至少 θ 位朋友都在跑才會加入。同樣兩種網路，讀者會看到結果反過來：三角形多的網路讓晨跑傳開，捷徑則「浪費」了接觸。
- **場景 C：你來排宿舍**。讀者有固定數量的連結，要決定放在哪裡，目標是讓晨跑傳最多、流感傳最少。這是整個第一季的終點互動。

**④ 定義與結構**

```latex
\text{SIR: } \frac{dI}{dt} = \beta \langle k \rangle S I - \mu I, \qquad \text{網路上的傳播門檻 } \left(\frac{\beta}{\mu}\right)_c \approx \frac{\langle k \rangle}{\langle k^2 \rangle}, \qquad \text{門檻規則: } x_i(t{+}1) = \mathbb{1}\Big[\sum_j A_{ij} x_j(t) \ge \theta\Big]
```

- 均勻混合的 SIR 有單一的 R₀。放到網路上時，門檻和 ⟨k²⟩ 有關：度分布越不平均，門檻越低。這和第 5 章的 ⟨k²⟩/⟨k⟩ 是同一個量，要明確指出來。
- 簡單傳染：一次接觸就可能傳染，捷徑讓它跨圈。複雜傳染：需要多個來源「增強」，而捷徑只提供一個來源。只有「寬橋」（多條平行的跨圈連結）才能傳複雜傳染。

**⑤ 邏輯鏈**

1. 假設：採用行為需要多位朋友的強化（θ ≥ 2），而感染病毒只需一次接觸。
2. 推導：三角形多的網路裡，兩位已採用者很可能有共同朋友，強化自然發生；隨機網路裡，接觸分散、很少人同時收到兩個來源。
3. 結果：對行為來說，聚集的網路比隨機網路更有效；對病毒則相反。
4. 預測：可以用實驗檢驗：同樣的人、同樣的度，只改網路結構。

「拿掉假設」：把 θ 調回 1，結果就變回第 4 章的捷徑最有效。

**⑥ 真實資料**：[Centola 2010](https://pubmed.ncbi.nlm.nih.gov/20813952)（*Science*）。[1,528 位參與者](https://arxiv.org/pdf/1901.02125)被分配到人為設計的線上健康社群，網路結構是「聚集格子」或對應的隨機網路。[行為在聚集網路上傳得更遠、更快](https://faculty.cs.byu.edu/%7Emike/mikeg/papers/SpreadofBehaviorinSocialNetworkExperimentScience.pdf)，參與者收到多位鄰居的強化時採用機率大幅上升。揭曉圖：兩條採用曲線，對照讀者的二選一。再回收第 5 章 Christakis 和 Fowler 的流感資料，把兩種傳染並排。

**⑦ 意義**

- **社會學**：社會運動、高風險的參與需要強連結和密集的群體（McAdam 對 1964 年 Freedom Summer 的研究）。資訊靠弱連結，行動靠強連結，這把第 3 章和第 6 章接起來。
- **經濟學**：當採用一項技術的好處取決於朋友是否也採用（網路外部性、協調賽局），採用就是複雜傳染。Morris（2000）用賽局論給出「什麼網路結構能讓新習俗擴散」的條件。推廣新制度時，要先在一個小圈子內搭高密度，而不是大範圍稀釋。

**⑧ 限制**：線上實驗的「行為」很輕量；現實中病毒和行為會交互影響（防疫行為）。下一個問題：這些網路是怎麼長出來的？→ 第二季：合作網路。

*待查證：McAdam 1986、Morris 2000、Pastor-Satorras & Vespignani 2001 的出處細節。*

## 技術架構與 repo 結構

網站是靜態網站，用 Astro 產生頁面、Svelte 寫互動元件、MDX 寫內文，用 GitHub Actions 部署到 GitHub Pages。沒有後端、沒有資料庫。

### 技術選型

| 層 | 選擇 | 理由 |
| --- | --- | --- |
| 網站框架 | Astro | 內容為主、多頁面；預設不送 JS，只在互動元件處載入（islands） |
| 互動元件 | Svelte | 樣板少、反應式狀態簡單，The Pudding 等視覺敍事團隊常用 |
| 內文 | MDX | 作者可以直接改文字，在文字中插入 `<FormulaCard>` 等元件 |
| 小人繪圖 | PixiJS（WebGL，自動退回 Canvas） | 上百個有動畫的 sprite 仍維持 60 fps |
| 網路排版 | d3-force | 業界標準，可以控制力的參數並持續更新 |
| 圖表 | d3-scale / d3-shape + Svelte 自寫 SVG | 圖表樣式全部自己控制 |
| 公式 | KaTeX（建置時預先繪製） | 快；靜態輸出不需客戶端 JS |
| 捲動敘事 | Scrollama（或 IntersectionObserver 自寫） | 輕量 |
| 網路演算法 | 自寫 TypeScript 模組（BFS、聚集係數、中心性、Louvain、SIR） | 可在瀏覽器即時算，並以 networkx 的結果做單元測試 |
| 資料前處理 | Python + networkx，輸出 JSON | 可重現；處理公開資料集（空手道社、佛羅倫斯婚姻網路） |
| 部署 | GitHub Actions → GitHub Pages | 免費；push 到 main 就自動發布 |

所有套件在建立 repo 時釘住當下的穩定版本（寫入 lockfile），不使用 `latest`。

### 真實資料怎麼進到網站

- 有公開原始網路的（空手道社、佛羅倫斯婚姻網路）：原始資料放 `data/raw`，用腳本算指標，輸出 JSON。
- 只有論文結果的（Facebook、LinkedIn、哈佛流感）：只輸入論文報告的數字，每筆資料附 `source` 欄位（論文、圖號或表號、頁碼）。不要從圖片「估」數字；如果論文只有圖沒有表，在 JSON 裡標註 `digitized: true` 和數位化的方法。

### 效能與無障礙

- 每章首次載入的 JS < 300 KB（gzip）；Lighthouse 效能 ≥ 90。
- 互動元件在捲入視窗時才初始化。
- 所有控制項可用鍵盤操作；網路圖附文字替代（例如「目前平均距離 3.2、聚集係數 0.41」）。
- 支援 prefers-reduced-motion 和深色模式。
- 手機（寬 375px）、平板、桌機三種版型都要測。

## 給 Claude Code 的施工說明

開發分五個階段，每個階段結束都要能部署、能給人看。一個章節一個 PR，作者審過才合併。

### 開發順序

1. **骨架**：建 repo、Astro + Svelte + MDX、設計 tokens、首頁課程地圖（全部章節顯示「製作中」）、GitHub Pages 自動部署。
   - 驗收：push 後 5 分鐘內網站更新；深淺色主題都正確。
2. **圖演算法庫**：`lib/network` 實作 BFS、度分布、聚集係數、三種中心性、模組度、Louvain、Watts–Strogatz、SIR 與門檻模型。
   - 驗收：每個函式在空手道社和佛羅倫斯網路上的結果與 networkx 一致（由 Python 腳本產生期望值）。
3. **共用元件**：小人引擎、雙視圖、Predict、LogicChain、FormulaCard、RevealChart，以及一個 `/playground` 頁展示每個元件的所有狀態。
   - 驗收：200 個小人在一般筆電上 60 fps；手機上 ≥ 30 fps；視圖切換無跳動。
4. **第一個完整章節：第 6 章弱連結**。它用到最多元件（兩個場景、拿掉假設、四筆真實資料），是最好的完整測試。做完後請大學生試讀，修正模板。
   - 驗收：符合該章規格底下的驗收清單；3 位試讀者能在讀完後說出章末那一句話。
5. **其餘八章**：建議順序 1 → 3 → 4 → 5 → 2 → 7 → 8 → 9。每章一個 PR。
