# 第 6 章　暑期實習，是誰介紹的？

**概念**：連結強度、鄰居重疊度、橋與局部橋、弱連結的力量、滲流。**前置**：聚集係數、小世界。**帶走的一句話**：新資訊只能從橋上進來，而橋幾乎都是弱連結。但「最弱」不是最好。

**① 場景**：大三經濟系的小瑜在找暑期實習。她最好的朋友們和她修一樣的課、投一樣的公司，知道的職缺也都一樣。最後介紹她進公司的，是大一服務學習課上只見過幾次面的學姊。

**② 預測**：「透過人脈找到工作的人中，介紹人是『常常見面』、『偶爾見面』、『很少見面』的各佔多少？」拖一個三段的比例條。

**③ 動手玩**

- **場景 A：職缺怎麼傳到你手上**。校園視圖裡約 70 位學生，分成幾個系和社團的小圈圈。連結粗細是模擬中累積的相遇次數。一個發光的「實習職缺」從某個圈圈出現，沿連結傳出去。讀者可以切換「只透過強連結傳」和「也透過弱連結傳」，看職缺能不能跑出圈子、多久到小瑜手上。
- **場景 B：剪斷實驗**。兩個按鈕：「從最弱的開始剪」和「從最強的開始剪」。小人網路即時斷裂，旁邊同步畫出最大連通群比例 S(f)。剪弱的時網路在某個門檻崩解，剪強的只會慢慢縮小。

**④ 定義與結構**

```latex
O_{ij} = \frac{n_{ij}}{(k_i - 1) + (k_j - 1) - n_{ij}}, \qquad S(f) = \frac{|\text{最大連通群}|}{N}\ \text{（剪掉 } f \text{ 比例的連結後）}
```

- w\_ij 是連結強度（見面頻率、通話時間）。n\_ij 是 i、j 的共同朋友數。O\_ij = 0 代表局部橋，O\_ij = 1 代表兩人朋友圈完全重疊。
- 橋：拿掉後網路分裂的連結。局部橋：兩端沒有共同朋友的連結；它的「跨度」是拿掉後兩端的距離。
- S(f) 在某個 f\_c 突然掉到接近 0，是一個相變。這是物理系讀者會認得的滲流門檻。

**⑤ 邏輯鏈**（「拿掉這個假設」的示範章）

1. 假設：Granovetter 的「禁止三角形」。如果 A–B 和 A–C 都是強連結，B–C 至少有弱連結。
2. 推導：任何局部橋都不可能是強連結。反證：若 A–B 是強連結又是局部橋，而 A 還有其他強連結 C，則 B–C 必存在，A–B 就不是局部橋了。用三個小人的動畫示範。
3. 結果：強連結的朋友知道的事你大多也知道，新資訊從弱連結進來。
4. 預測：(a) 工作資訊多半來自弱連結；(b) 連結越強，O\_ij 越高；(c) 先剪弱連結會讓網路崩解。

讀者點「拿掉禁止三角形」時，第 2–4 格變灰，並顯示：「強連結也可以是橋，弱連結的優勢就不再保證」。

**⑥ 真實資料**

- **Granovetter 1973**：透過人脈找到工作的人中，[16.7% 的介紹人是常見面的，55.6% 是偶爾見面的，27.8% 是很少見面的](https://law-journals-books.vlex.com/vid/labor-market-implications-weak-ties-54952367)。對照第 ② 段的比例條。
- **[Onnela 等人 2007](https://pubmed.ncbi.nlm.nih.gov/17456605/)**（*PNAS*）：數百萬手機用戶的通話網路。連結強度和局部結構耦合；剪強連結網路仍穩健，剪弱連結則在一個相變後崩解。預測 (b)、(c) 成立。場景 B 就是重現這張圖。
- **[Rajkumar 等人 2022](https://pubmed.ncbi.nlm.nih.gov/36107999/)**（*Science*）：LinkedIn [在五年間對超過 2,000 萬人](https://ide.mit.edu/wp-content/uploads/2022/09/abl4476.pdf?x19295)隨機調整「你可能認識的人」推薦，[產生約 20 億條新連結和 60 萬份新工作](https://www.Gwern.net/doc/sociology/technology/2022-rajkumar.pdf)。結果是倒 U 型：用共同朋友數衡量時，「中等弱」的連結最能帶來新工作。這是「真實資料修正理論」的時刻。
- **反例：[邊燕傑 1997](https://acnpsearch.tweb-dev.unibo.it/singlejournalindex/7426245)**（*ASR*）：1988 年天津的調查發現，工作更常透過強連結取得，因為「關係」傳遞的是影響力而非資訊。留一個問題給讀者：台灣比較像哪一邊？

**⑦ 意義**

- **經濟學**：勞動市場有資訊摩擦，網路是搜尋的管道。[Calvó-Armengol 和 Jackson 2004](https://econpapers.repec.org/RePEc:aea:aecrev:v:94:y:2004:i:3:p:426-454)（*AER*）證明：當工作資訊沿網路流動時，就業狀態在朋友之間正相關，一個起點較差的群體會持續落後。內推制度會複製不平等。
- **社會學**：社會資本有兩種來源。Burt 的結構洞強調橋帶來新資訊；Coleman 的封閉性（第 3 章）強調強連結帶來信任。倒 U 型結果說明兩者需要平衡：太弱的連結沒人願意幫你。

**⑧ 限制**：「強度」該用互動頻率還是共同朋友數？兩者在 LinkedIn 研究中結果不同；文化差異。下一個問題：如果橋這麼重要，站在橋上的人是不是很有權力？→ 第 7 章。

**驗收**：剪斷時連結有斷裂動畫，S(f) 曲線同步更新、延遲 < 100ms；重繪倒 U 圖時標出「共同朋友數」是 x 軸定義；手機寬度下兩個場景都可操作。
