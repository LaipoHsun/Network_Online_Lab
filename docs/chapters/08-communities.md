# 第 8 章　社團吵架分成兩派：演算法猜得到誰站哪邊嗎？

**概念**：社群（community）、模組度（modularity）、社群偵測。**前置**：度、聚集係數、介數中心性。**帶走的一句話**：「群」的定義是「內部連結比隨機預期的多」，而不是「內部連結很多」。

**① 場景**：台大某個武術社，社長和教練為了是否要漲社費吵了一學期。社員們開始選邊站。問題：如果只知道「誰和誰在社辦外也會一起出去」，能預測分裂後每個人站哪一邊嗎？

**② 預測**：讀者在 34 人的網路上自己畫一條線把社團分成兩半（拖曳小人到左右兩邊）。送出後計算他的分法的 Q 值。

**③ 動手玩**

- **場景 A：你來分群**。讀者拖曳小人到不同的顏色區，Q 值即時更新。內部連結變綠、跨群連結變橘。可以按「讓演算法來」看 Louvain 一步一步合併。
- **場景 B：切斷橋樑**。Girvan–Newman 演算法的動畫版：反覆移除介數最高的連結，社團自己裂成兩半。這把第 7 章和本章接起來。
- \*\*場景 C：隨機網路也有「群」嗎？\*\*在一個隨機網路上跑同一個演算法，也會得到正的 Q。用來講「找到群」不等於「群是真的」。

**④ 定義與結構**

```latex
Q = \frac{1}{2m}\sum_{i,j}\left[A_{ij} - \frac{k_i k_j}{2m}\right]\delta(c_i, c_j)
```

- m 是連結數，c\_i 是 i 的群別。k\_i k\_j / 2m 是「保留每個人度數的隨機網路」裡 i、j 之間的預期連結數（configuration model）。
- Q 是「實際的群內連結比例減掉預期比例」。把所有人放在一群時 Q = 0。
- 結構性質：最大化 Q 是 NP-hard，所以都用啟發式演算法；有解析度限制（太小的群會被合併）；物理系讀者可以認出它和 Potts 模型能量函數的對應。

**⑤ 邏輯鏈**

1. 假設：群內的人互動比隨機預期多，群間的互動比預期少。
2. 推導：沒有任何「標籤」，只看連結結構就能找出使 Q 最大的分法。
3. 結果：網路結構裡藏著社會分組。
4. 預測：當群體真的分裂時，分裂線會沿著演算法找出的邊界走。

**⑥ 真實資料**：[Zachary 空手道社](https://en.wikipedia.org/wiki/Zachary%27s_karate_club)。Zachary 在 1970–1972 年觀察了美國一所大學空手道社 34 位在社團外也有互動的成員。期間管理者「John A」和教練「Mr. Hi」產生衝突，社團分裂為二，[Zachary 的方法正確預測了除一人外所有人的去向](https://www.wikipedia.org/wiki/Zachary_Karate_Club)。Girvan 和 Newman 2002 年用它測試社群偵測，[也只分錯一個節點](https://arxiv.org/pdf/0905.4103)。揭曉動畫：先顯示讀者的分法，再顯示演算法的分法，最後顯示真實的分裂，那個被分錯的人要特別標出來討論。可加入 Facebook100 的「年級主導社群」作為大尺度的例子（第 2 章）。

**⑦ 意義**

- **社會學**：派系、階級、極化都可以是「網路裡的群」。群之間連結稀少，代表對立的兩邊很少有直接對話的管道。
- **經濟學**：社群結構會將資訊困在群內，形成「資訊孤島」；Onnela 2007 的模擬也顯示資訊會被困在社群裡（第 6 章）。群內的高信任也支撑非正式保險和合作。

**⑧ 限制**：模組度有解析度限制；真實的人可能同時屬於多個群（重疊社群）；34 人的例子很經典但很小。下一個問題：這些群和橋，影響東西怎麼傳開嗎？→ 第 9 章。
