# 第 7 章　系學會的消息，為什麼都經過他？

**概念**：中心性（centrality）：度、接近、介數、特徵向量。**前置**：路徑與距離、橋。**帶走的一句話**：「誰最重要」沒有唯一答案，每種中心性都對應一種「東西怎麼在網路上流動」的假設。

**① 場景**：政治系大二的子軒發現，系上什麼八卦都是從同一位學長傳出來的。他朋友不算最多，但他同時在系學會、籃球隊和吉他社。問題：朋友最多的人，就是最有影響力的人嗎？

**② 預測**：在一個 40 人的小人網路上點選「你覺得最重要的人」。之後四種中心性會各自指出一個人，看讀者的選擇和哪種一致。

**③ 動手玩**

- **場景 A：四種眼鏡**。同一張網路，切換四個按鈕，小人的大小跟著變。每種中心性配一個「流動」動畫：度 = 誰的對話框最多；接近 = 從他發出的漣漪最快覆蓋全體；介數 = 大量「信」穿過他；特徵向量 = 重複傳播時熱度累積在哪裡。
- **場景 B：拿掉一個人**。點一位小人讓他「休學」，看平均距離和最大連通群怎麼變。拿掉度最高的人和介數最高的人，結果往往不同。

**④ 定義與結構**

```latex
C_B(i) = \sum_{s \ne i \ne t} \frac{\sigma_{st}(i)}{\sigma_{st}}, \qquad C_C(i) = \frac{N-1}{\sum_j d_{ij}}, \qquad A\mathbf{x} = \lambda_1 \mathbf{x}
```

- 介數中心性：σ\_st 是 s 到 t 的最短路徑數，σ\_st(i) 是其中經過 i 的數量。它量的是「多少人之間的消息要靠你傳」。
- 接近中心性：平均距離的倒數。特徵向量中心性：你的重要性來自你朋友的重要性，是一個自我參照的定義，解是鄰接矩陣最大特徵值的特徵向量（Perron–Frobenius 保證它為正）。
- 結構關係：在很多網路裡四種中心性高度相關，但「度不高、介數很高」的人就是橋和經紀人，是最有趣的例外。

**⑤ 邏輯鏈**

1. 假設：資訊（或資源、權力）沿最短路徑流動。
2. 推導：位於很多最短路徑上的人能看到、延遲或改寫流過的東西。
3. 結果：介數中心性是一種「結構性權力」，不必然來自朋友多。
4. 預測：連接兩個不跟彼此往來的群體的人，能獲得不成比例的影響力。

「拿掉假設」：如果資訊是隨機遊走而不是走最短路徑，介數中心性就不是對的量尺，要改用特徵向量或 Katz 中心性。

**⑥ 真實資料**

- [Padgett 和 Ansell 1993](https://dl1.cuni.cz/mod/resource/view.php?id=341254)（*AJS*）：1400–1434 年佛羅倫斯菁英家族的婚姻與商業網路。梅迪奇家族的權力來自菁英網路中的斷裂處，而只有他們跨越了這些斷裂。後續分析發現[梅迪奇在婚姻網路中的度、接近、介數中心性都最高](https://arxiv.org/pdf/1401.0655)。揭曉圖：15 個家族的婚姻網路（公開資料集），節點大小 = 介數；讓讀者先在不知道名字時猜誰是梅迪奇。
- 回到 Milgram：[最後一站是「G 先生」的鏈佔了 64 條中的 16 條](https://www.cis.upenn.edu/~mkearns/teaching/NetworkedLife/navigation18.pdf)。

**⑦ 意義**

- **社會學**：Burt 的結構洞理論：位於兩個群體之間的人可以獲得資訊優勢和控制優勢。梅迪奇的「穩健行動」是歷史上的經典例子。
- **經濟學**：Ballester、Calvó-Armengol 和 Zenou（2006）證明，在有同儕外部性的賽局裡，均衡行為正比於 Katz–Bonacich 中心性；「關鍵人物」就是拿掉後總產出下降最多的人。Banerjee 等人（2013）在印度村莊發現，從中心性高的人開始推廣微型貸款，參與率更高。

**⑧ 限制**：中心性量的是「位置」不是「意願」；史料網路有倖存者偏誤。下一個問題：網路自己分成了哪幾群？→ 第 8 章。

*待查證：Ballester et al. 2006 (Econometrica)、Banerjee et al. 2013 (Science) 出處。*
