# 第 3 章　室友的朋友：為什麼朋友圈會「收合」？

**概念**：三元閉合（triadic closure）、聚集係數（clustering coefficient）、遷移性（transitivity）。**前置**：度、投影。**帶走的一句話**：社會網路的三角形比隨機網路多上好幾個數量級，而且這是一個「會自我強化」的過程。

**① 場景**：物理系大一的承恩和室友一起去吃宵夜，室友帶了自己的高中同學。一個學期後，他和那位同學已經會自己約打球。問題：兩個有共同朋友的陌生人，變成朋友的機率有多高？和共同朋友的數量有什麼關係？

**② 預測**：在一張空白圖上畫一條曲線：橫軸是共同朋友數（0–5），縱軸是「之後變成朋友的機率」。

**③ 動手玩**

- **場景 A：一個學期的宵夜**。60 位學生，每晚有人拉朋友一起去吃宵夜。新形成的三角形會閃一下。主要變數：「帶朋友去吃宵夜的機率」，也就是三元閉合的強度。另一個參照組是「隨機在餐廳遇到」。右側即時畫出 C(t) 和同樣連結數的隨機網路的 C。
- **場景 B：放大一個人**。點一位小人，畫面只留下他和他的朋友。朋友之間實際存在的連結亮起，可能存在但還沒存在的連結用虛線標出，直接對應公式的分子和分母。

**④ 定義與結構**

```latex
C_i = \frac{2L_i}{k_i(k_i-1)}, \qquad C_{\triangle} = \frac{3 \times \text{三角形數}}{\text{連通的三元組數}}, \qquad C_{\text{random}} \approx \frac{\langle k \rangle}{N}
```

- C\_i 的分母是 i 的朋友之間「最多可能」有幾條連結，分子 L\_i 是實際有幾條。範圍是 0 到 1。
- 平均局部聚集係數和全域遷移性是兩個不同的量，度很不均的網路裡可能差很多。這是讀論文時常見的陷阱，要講。
- 隨機網路的 C ≈ ⟨k⟩/N，會隨 N 變大而趨近 0。社會網路的 C 則大致不隨 N 變化。「C 不趨近 0」本身就是社會網路不是隨機的證據。
- 許多真實網路裡 C(k) 隨 k 下降：朋友很多的人，朋友之間比較不認識。

**⑤ 邏輯鏈**

1. 假設：有共同朋友的兩人，相遇機會更多（機會），也更信任彼此（信任），而且拒絕交流會讓共同朋友尷尬（平衡）。
2. 推導：共同朋友每多一位，相遇和成為朋友的機率就增加。
3. 結果：新連結偏好封閉三角形，三角形越多又讓下一次閉合更容易，C 維持在高水準。
4. 預測：「變成朋友的機率」隨共同朋友數上升。

**⑥ 真實資料**：[Kossinets 和 Watts 2006](https://cse.iitk.ac.in/users/cs888/files/good.pdf)（*Science*）分析了美國一所大型大學 43,553 位師生職員在一學年內[約 1,458 萬封 email](https://www.sciencenews.org/article/college-friendships-and-social-networks)，配對了每個人的身分、修課等屬性。[結果](https://research.google/pubs/origins-of-homophily-in-an-evolving-social-network/)顯示新連結的形成強烈偏向三元閉合和焦點閉合（同修一門課）：共同朋友和共同課程越多，形成新連結的機率越高。揭曉圖：重繪論文「新連結機率 × 共同朋友數 × 共同課程數」的圖，疊上讀者畫的曲線。另外可加一個小數字：[Pew 2012](https://www.pewresearch.org/internet/2012/02/03/part-3-the-structure-of-friendship) 樣本中，Facebook 用戶好友圈的平均密度是 0.12。

**⑦ 意義**

- **社會學**：Coleman 的「封閉性」論點。三角形多的群體容易建立規範和信任，因為你對一個人的行為，共同朋友都看得到。代價是資訊重複、觀點同質化，這正好是第 6 章弱連結的伏筆。
- **經濟學**：在合約無法執行的場合（借錢、互助、共同計畫），共同朋友就是執行機制：你違約，失去的不只一個關係。Jackson、Rodriguez-Barraquer 和 Tan（2012）把這個概念稱為「被支持的關係」。

**⑧ 限制**：email 不等於友誼；三元閉合和同質性、共同焦點很難分開。下一個問題：如果大家都只在自己的小圈圈裡，為什麼世界還是很小？→ 第 4 章。

*待查證：Jackson, Rodriguez-Barraquer & Tan 2012 (AER) 的出處細節。*
